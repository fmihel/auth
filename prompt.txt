Нужен совет по архитектуре.
Есть два класса js, 
class Request{
    async post(url,data){...}
}

class Session{
    constructor(request){
        this.request = request;
        this.token=...;
    }
    autorize(){
        // с помощью this,request получим token
    }
}


Request реализует метод отправки данных на сервер.
Session - класс авторизации, в методе autorize отправляет с помощью 
request запрос к серверу, и получает/хранит токен.

В дальнейшем предполагается использовать объект request для отправки 
запросов к серверу,что то типа: 
await request.post(url,data);

При этом, должны отрабатываться случаи с отказом по авторизации по token 
и случаи с отправкой неавторизованных запросов.
Пока видется два вариант с сохранением абстракции двух классов.
в сам post передавать дополнительно объект session, который будет 
формировать headers перед отправкой и проверять авторизацию ответа
request.post(url,data, session)
тогда вариант отправки без авторизации будет:
request.post(url,data)

Либо в Request добавить систему плагинов, которые будут работать примерно аналогично, предыдущего варианта
request.addPlugin(session);
авторизованные запросы тогда будут
request.post(url,data)
а неавторизованные ( придется отключать каким то образом plugin)
request.post(url,data,{disabled:[session]});
Возможно есть др варианты.
